# CHEROP workspace instructions

Before changing or adding UI, read WORKSPACE_DESIGN_RULES.md and the existing CSS/markup of the target area. Reuse established typography, spacing, tokens, square controls and compact tables. Do not introduce a separate visual theme. Keep the production studio inside the AI organization tabs.

Preserve concurrent work. Fetch the latest main, change only relevant files, and publish with a branch-head lease. Do not restore older full files over other changes.

For production tasks, also read production-engine/README.md. Preserve approved originals. A ZIP is a download package, not a directly viewable preview; deliver a separate self-contained HTML preview.
